# Training Guide for Team Members

## Session Agenda (45 Minutes)

1. **System Architecture Overview (10 mins)**
   - Walkthrough of the React 18 frontend and FastAPI backend.
   - Dual retrieval paths: Flat Qdrant vectors vs Neo4j knowledge graphs.

2. **Core Feature Walkthrough (20 mins)**
   - Querying in Compare Tab.
   - Multi-turn conversation and session management in Chat Tab.
   - Subgraph exploration in Analytics Tab.
   - User administration and document ingestion in Admin Tab.

3. **Hands-On Exercises & Q&A (15 mins)**
   - Exercise 1: Run exposure query across schemes.
   - Exercise 2: Switch personas via User Profile Switcher.
   - Exercise 3: Inspect token savings in Telemetry cards.
