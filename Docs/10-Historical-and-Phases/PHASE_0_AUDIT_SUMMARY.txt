KEY IMPLEMENTATION DETAILS
───────────────────────────────────────────────────────────────────────────────

REVIEW QUEUE
  ├─ Escalation: /api/review-queue/escalate (POST)
  ├─ Assignment: /api/review-queue/{id}/assign (POST)
  ├─ Approval: /api/review-queue/{id}/approve (POST)
  ├─ Rejection: /api/review-queue/{id}/reject (POST)
  ├─ Statistics: /api/review-queue/stats (GET)
  └─ Database: SQLite, auto-priority calculation, governance tracking

NLI & VERDICT GENERATION
  ├─ Tier 0: Rule-based (prohibited guarantees, hallucination flags)
  ├─ Tier 1: NLI semantic (contradiction≥0.75, entailment≥0.85)
  ├─ Tier 2: Heuristic (confidence-based)
  ├─ Fallback: Heuristic engine if neural unavailable
  └─ Output: Verdict enum + metadata dict

SCHEDULER
  ├─ Job 1: SEBI polling (3:00 AM UTC daily)
  ├─ Job 2: Staleness check (6:00 AM UTC daily)
  ├─ Job 3: Governance batch (9:00 AM UTC Fridays)
  ├─ Job 4: Cache maintenance (2:00 AM UTC daily)
  ├─ Job 5: Metrics aggregation (every hour)
  ├─ Engine: APScheduler (or FallbackScheduler fallback)
  └─ Execution: Async/sync via job_wrapper

RATE LIMITING
  ├─ IP Rate Limiter: 60 req/60s (per IP)
  ├─ User Quotas: Tier-based (free/premium/enterprise/admin)
  ├─ Free Tier: 10 req/hr, 100 req/day
  ├─ Premium: 1000 req/hr, 10k req/day
  ├─ Response: 429 with Retry-After header
  └─ Middleware: Transparent enforcement (except exempt paths)

INPUT VALIDATION
  ├─ SQL Injection: UNION, DROP, semicolon detection
  ├─ XSS: Script tags, javascript: URIs
  ├─ Repetition: Degenerate query detection
  ├─ Framework: Pydantic validators
  └─ Enforcement: At model instantiation time
