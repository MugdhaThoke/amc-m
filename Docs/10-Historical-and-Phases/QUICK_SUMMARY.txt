KEY FINDINGS:
================================================================================

WHY RUST FAILED:
  Problem: FFI serialization overhead (JSON round-tripping) dominates
  Result:  Rust 4X SLOWER than Python due to JSON serialization per fund
  Lesson:  Don't use Rust for fast, lightweight operations

Benchmark Results:
  1,000 funds:  Python 7.48ms   vs Rust 26.48ms  (0.28x)  X
  5,000 funds:  Python 28.89ms  vs Rust 125.85ms (0.23x) X
  10,000 funds: Python 121.97ms vs Rust 288.93ms (0.42x) X

IDENTIFIED PYTHON BOTTLENECKS (Ready to fix):
  1. Regex condition parsing        0.5-1ms/rule   (2-3x improvement available)
  2. Metric path string split       0.5ms/metric   (2-3x improvement available)
  3. Lambda operator dispatch       0.1-0.2ms      (1.5-2x improvement available)
  4. Sequential rule loop           N*M             (3-5x improvement available)
  5. Per-violation Neo4j writes     10-50ms each   (10-20x improvement available!)

================================================================================
DECISION FRAMEWORK (for future projects):
================================================================================

Use Rust if:
  CHECK Computation time >> FFI overhead (compute-intensive)
  CHECK Parallelization enabled (rayon available)
  CHECK Batch operations (amortize FFI cost)
  CHECK Direct memory access (no JSON serialization)

Use Python if:
  CHECK Operations are fast (<100us)
  CHECK I/O-bound (network dominates)
  CHECK FFI overhead > savings
  CHECK Team expertise/maintainability matters

================================================================================
LESSONS LEARNED:
================================================================================

1. AppLocker blocks Rust proc-macro crates
   Solution: Build in C:\temp (side-stepped successfully)

2. FFI overhead is real and significant
   Impact: JSON serialization > computation in this case

3. Don't assume language = performance
   Lesson: Profile first, then decide (not the reverse)

4. Python has 15-50x improvement potential
   Opportunity: This beats any Rust benefits (which showed -60% slowdown)
